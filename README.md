# Experimental Analysis of Physical Properties in Pure and Commercial Edible Oils

## 📌 Project Overview

This project is a web-based oil analysis system developed to compare the physical properties of an original reference coconut oil with selected commercial coconut oil samples.

The system uses experimentally measured temperature, density, and flow time to calculate parameter-wise differences, similarity scores, and rankings.

## 🎯 Objectives

- Measure physical properties of coconut oil samples.
- Compare commercial samples with an original reference oil.
- Calculate percentage differences between samples.
- Generate similarity scores and rankings.
- Visualize experimental results using charts.
- Provide a simple web-based analysis system.

## 🧪 Experimental Parameters

| Parameter | Unit |
|---|---|
| Temperature | °C |
| Density | g/mL |
| Flow Time | seconds |

## ⚙️ Analysis Method

The system follows this workflow:

**Experimental Measurement → Data Entry → Data Processing → Percentage Difference → Similarity Score → Ranking → Visualization**

The commercial samples are compared against the Original Coconut Oil reference.

## 💻 Software Features

- Original oil reference input
- Commercial sample data entry
- Temperature analysis
- Density analysis
- Flow-time analysis
- Percentage difference calculation
- Similarity score calculation
- Sample ranking
- Data visualization
- Results table
- Responsive web interface

## 📊 Project Scope

The current experimental implementation focuses on selected physical properties:

- Temperature
- Density
- Flow Time

The system identifies the commercial sample whose measured properties are closest to the Original Coconut Oil based on the selected parameters.

## ⚠️ Limitation

The similarity score is based only on the selected experimental physical parameters. It does not independently prove oil purity, authenticity, safety, nutritional quality, or absence of adulteration.
